Using a non-string value (e.g. a TOML array) for a ``string``-typed option in the ``[tool.pytest.ini_options]`` table is now deprecated and emits a :class:`~pytest.PytestRemovedIn10Warning`.
It will become an error in pytest 10, matching the behavior of the ``[tool.pytest]`` table.

See :ref:`ini-string-non-string-value` for details.
