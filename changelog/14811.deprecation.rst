Setting a ``string``-typed ini option to a non-string value (such as a TOML array) in the ``[tool.pytest.ini_options]`` table is now deprecated and emits a :class:`~pytest.PytestRemovedIn10Warning` -- see :ref:`ini-string-non-string-value`.
This will become an error in pytest 10, matching the behavior of ``[tool.pytest]`` and ``pytest.toml``.
