Passing a value that is not a string (e.g. a TOML array) to a ``string``-typed ini option in the ``[tool.pytest.ini_options]`` table is now deprecated and emits :class:`~pytest.PytestRemovedIn10Warning`; it will become a :class:`TypeError` in pytest 10, matching the behavior of the ``[tool.pytest]`` table.

See :ref:`ini-string-non-string-value` for details.
